# Learning Repository

This repository contains code examples and exercises for learning fundamental Node.js and JavaScript concepts.

## Structure

- `async_await_promise`: Examples of asynchronous programming using Promises and async/await.
- `callback_stack`: Understanding the call stack and callback execution order.
- `evenloop`: Demonstrations of the Node.js Event Loop mechanism.
- `redis`: Examples of integrating with Redis using Node.js.
- `streams`: Working with Node.js streams for efficient I/O operations.
